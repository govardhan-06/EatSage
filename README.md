# EatSage

## "Eating Made Easier"

### Project Introduction
EatSage is a cutting-edge food delivery application that integrates AI and Blockchain technology to provide a seamless and secure user experience. The app leverages three specialized AI agents to handle specific tasks in the food ordering and delivery process:
- **Customer Agent**
- **Restaurant Agent**
- **Valet Agent**

### Key Features
- **AI Integration**: Automates food booking tasks, ensuring convenience by suggesting meals based on user preferences and health conditions.
- **Blockchain Security**: Ensures data privacy by processing payments through the Fetch Blockchain, securing sensitive health information.
- **User-Friendly Interface**: Simple chat interface and location-based restaurant filtering make the app easy to use.
- **Enhanced Privacy & Security**: Blockchain integration safeguards user data and transactions.

---
## Tech Stack
- **Frontend**: Flutter - Provides a seamless and responsive user experience across mobile, web, and desktop platforms.
- **Backend**: Fetch.ai Framework - Enables decentralized autonomous agents for secure and efficient interactions.
- **AI Model**: Falcon-180M-Chat (AI71 Labs) - Powers the Customer Agent, utilizing natural language processing to enhance user interaction.
- **Backend Services**: FASTAPI - Ensures high-performance and reliable API interactions.

## Prototype Workflow
1. **User Preference Submission**: AI processes user input to generate meal suggestions.
2. **Order Placement**: AI-generated meal order is confirmed and forwarded to the Restaurant Agent.
3. **Restaurant Interaction**: Restaurant accepts or denies the order, notifying the user.
4. **Valet Management**: Valet Agent can accept or deny the delivery request.
5. **Delivery & Payment**: Payment is conducted via test FET tokens, ensuring a seamless transaction process.
